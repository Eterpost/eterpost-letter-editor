# Changelog

Все заметные изменения eterpost-letter-editor. Версии — по [Semantic Versioning](https://semver.org/);
до 1.0 минорная версия приносит новое, патч — исправления.

## 0.1.0 — 2026-11-17

- Первая версия: редактор письма Почтаря отдельным пакетом — визуальный редактор и
  HTML, кнопки «Вставить поле» с подписями от хозяина, предупреждения о пустых
  подстановках, загрузка картинок через функцию хозяина, свои вкладки.
- Вход `eterpost-letter-editor/fields` без React: сводка по получателям и разбор
  полей шаблона.
- Стили только внутри `.le-editor`, цвета — переменные `--le-*` на `.le-editor` или
  выше; тема — по системе или `colorScheme`.
